# Contributing

Thank you for contributing to AI Quota Monitor.

1. Open an issue before large behavioral or protocol changes.
2. Keep authentication data local and never add cookies, tokens, account dumps, or signed build artifacts.
3. Preserve both Simplified Chinese and English UI strings.
4. Run `./scripts/test.sh` and the Swift type-check command from the README.
5. For widget changes, run `./scripts/build-widget.sh` and `./scripts/verify-widget.sh` with your own Apple signing setup.
6. Keep pull requests focused and describe user-visible behavior and validation.

Do not include screenshots or fixtures containing account identifiers or private quota-session data.
