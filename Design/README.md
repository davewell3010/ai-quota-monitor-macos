# Star Orbit 2.0 design previews

`star-orbit-v2-portrait.png` and `star-orbit-v2-horizontal.png` are generated visual concepts, not screenshots of the app. Some text and values in them are illustrative and may not agree mathematically.

`star-orbit-v2-app-vertical.png`, `star-orbit-v2-app-horizontal.png`, and `star-orbit-v2-app-disconnected.png` are renders from the SwiftUI app in preview mode. Preview mode uses sample quota values and does not access accounts. The connected app uses live provider snapshots.

The optional Star Orbit theme affects the floating card and its settings palette. It does not change the WidgetKit desktop widget.

`hero-comic-app-vertical.png`, `hero-comic-app-horizontal.png`, and `hero-comic-app-disconnected.png` are SwiftUI preview renders of the original Hero Comic theme. They use sample data; the running app uses live provider snapshots. This theme uses code-drawn shapes and colors, not franchise art or logos.
